## ADDED Requirements

### Requirement: Коэффициент «жёсткости» бюджета

Система SHALL отображать долю дохода текущего месяца, уходящую на обязательные
регулярные платежи, как компактный индикатор рядом с индексом свободы.

#### Scenario: Расчёт коэффициента
- **WHEN** доход за месяц составляет 100 000 ₽, а сумма активных регулярных
  платежей — 40 000 ₽
- **THEN** система показывает коэффициент 40%

#### Scenario: Доход за месяц равен нулю
- **WHEN** за текущий месяц ещё не зафиксировано ни одного дохода
- **THEN** система показывает «неизвестно» вместо деления на ноль

### Requirement: REST API коэффициента жёсткости бюджета

Backend SHALL предоставлять `GET /api/v1/analytics/fixed-cost-ratio?year=&month=`,
возвращающий сумму дохода за месяц, сумму активных регулярных платежей и
вычисленное отношение.

#### Scenario: Запрос коэффициента
- **WHEN** клиент запрашивает `GET /api/v1/analytics/fixed-cost-ratio?year=2026&month=7`
- **THEN** ответ `200` содержит `income`, `mandatory_total`, `ratio` (`null`, если
  `income = 0`)
