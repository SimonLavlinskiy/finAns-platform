## ADDED Requirements

### Requirement: Тренд доли трат «по желанию»

Система SHALL отображать линейный график доли расходов со специфичностью «Простой»
(по желанию) от суммы всех расходов, по месяцам, за последние 12 месяцев.

#### Scenario: Расчёт доли за месяц
- **WHEN** за месяц сумма «простых» расходов составляет 30 000 ₽, а общая сумма
  расходов — 100 000 ₽
- **THEN** график показывает долю 30% за этот месяц

#### Scenario: Месяц без расходов
- **WHEN** за какой-то месяц в 12-месячном окне нет ни одной транзакции-расхода
- **THEN** график показывает разрыв линии за этот месяц, а не значение 0%

#### Scenario: Заметность виджета
- **WHEN** пользователь открывает страницу `/analytics`
- **THEN** график индекса свободы расположен на видном месте (не требует
  прокрутки страницы для первого просмотра на десктопе)

### Requirement: REST API индекса свободы

Backend SHALL предоставлять `GET /api/v1/analytics/freedom-index?months=N`,
возвращающий для каждого из последних N месяцев (по умолчанию 12) сумму «простых»
расходов, общую сумму расходов и вычисленную долю (или `null`, если расходов не было).

#### Scenario: Запрос индекса свободы
- **WHEN** клиент запрашивает `GET /api/v1/analytics/freedom-index?months=12`
- **THEN** ответ `200` содержит 12 элементов, упорядоченных по месяцу, с полями
  `month`, `simple_amount`, `total_expense`, `share` (`share = null`, если
  `total_expense = 0`)

### Requirement: Симулятор «что если» для индекса свободы

Под графиком индекса свободы система SHALL предоставлять слайдер целевой доли
«простых» трат, показывающий прогнозируемую годовую экономию при достижении
выбранной доли, рассчитанную на основе данных последнего полного месяца.

#### Scenario: Расчёт прогнозируемой экономии
- **WHEN** текущая доля «простых» трат — 40% (40 000 ₽ из 100 000 ₽ за последний
  полный месяц), пользователь двигает слайдер на целевые 20%
- **THEN** система показывает прогнозируемую экономию `(40 000 − 20 000) × 12 =
  240 000 ₽` в год

#### Scenario: Слайдер не отправляет запросы на сервер
- **WHEN** пользователь двигает слайдер симулятора
- **THEN** значение экономии пересчитывается мгновенно на уже загруженных данных,
  без обращения к API

#### Scenario: Целевая доля выше текущей
- **WHEN** пользователь выставляет целевую долю выше текущей фактической доли
- **THEN** прогнозируемая экономия показывается как отрицательная (перерасход) или
  скрывается с поясняющим текстом — не отображается как положительная экономия
