## ADDED Requirements

### Requirement: Лента текстовых инсайтов

Страница аналитики SHALL отображать до 3 автоматически сгенерированных текстовых
инсайтов на основе детерминированных правил сравнения текущего месяца с историей.

#### Scenario: Значимый рост расходов по тегу
- **WHEN** расходы по тегу выросли более чем на 20% и более чем на 1000 ₽
  по сравнению со средним за предыдущие 3 месяца
- **THEN** отображается инсайт с названием тега и величиной роста

#### Scenario: Незначительная дельта не порождает инсайт
- **WHEN** расходы по тегу выросли на 25%, но абсолютная дельта меньше 1000 ₽
- **THEN** инсайт по этому правилу не отображается

#### Scenario: Самая крупная транзакция месяца
- **WHEN** пользователь открывает страницу аналитики в середине месяца, по которому
  уже есть расходы
- **THEN** один из инсайтов называет наименование и сумму самой крупной
  транзакции-расхода этого месяца

#### Scenario: Новый тег в текущем месяце
- **WHEN** в текущем месяце впервые появилась транзакция с тегом, по которому
  раньше не было расходов
- **THEN** отображается инсайт о новой категории расходов

#### Scenario: Ни одно правило не сработало
- **WHEN** ни одно из правил инсайтов не выполняется (например, недостаточно
  истории)
- **THEN** лента инсайтов не отображается (пустой блок скрывается, а не
  показывается с заглушкой)

### Requirement: REST API инсайтов

Backend SHALL предоставлять `GET /api/v1/analytics/insights`, возвращающий массив
из 0-3 сработавших инсайтов с готовым текстом на русском языке.

#### Scenario: Запрос инсайтов
- **WHEN** клиент запрашивает `GET /api/v1/analytics/insights`
- **THEN** ответ `200` содержит массив объектов с полями `type`, `text`
