## ADDED Requirements

### Requirement: Страница «Аналитика»

Приложение SHALL предоставлять отдельную страницу `/analytics` с пунктом навигации
«Аналитика», объединяющую: ленту инсайтов, индекс свободы (с симулятором «что
если») и коэффициент жёсткости бюджета, Sankey-диаграмму, прогноз баланса,
прогноз накопления на товары вишлиста, календарь по «настроению» трат, сравнение
периодов и панель лимитов трат.

#### Scenario: Переход на страницу аналитики
- **WHEN** пользователь кликает на пункт навигации «Аналитика»
- **THEN** открывается `/analytics` со всеми виджетами аналитики

#### Scenario: Изоляция от остальных страниц
- **WHEN** любой виджет страницы аналитики обращается к данным других фич
  (вишлист, регулярные платежи, транзакции)
- **THEN** используется только чтение через существующие `GET`-эндпоинты; ни один
  файл, относящийся к другим страницам приложения (включая `ExpensesCalendar` на
  `/transactions`), не изменяется этим change

### Requirement: Общий выбор периода для новых виджетов

Sankey-диаграмма, календарь по «настроению» трат и сравнение периодов SHALL
использовать общий выбор периода (месяц/год) на странице аналитики.

#### Scenario: Смена периода обновляет виджеты
- **WHEN** пользователь меняет месяц в переключателе периода на `/analytics`
- **THEN** Sankey-диаграмма и календарь по «настроению» трат обновляются на
  выбранный период
