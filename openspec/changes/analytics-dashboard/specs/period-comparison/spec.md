## ADDED Requirements

### Requirement: Сравнение текущего периода с прошлым

Система SHALL отображать столбчатое сравнение расходов по топ-5 категориям текущего
месяца с предыдущим месяцем или с тем же месяцем год назад.

#### Scenario: Сравнение с прошлым месяцем
- **WHEN** пользователь выбирает режим «vs прошлый месяц»
- **THEN** для каждой из топ-5 категорий текущего месяца отображается пара
  столбцов: текущий месяц и предыдущий

#### Scenario: Сравнение с тем же месяцем год назад
- **WHEN** пользователь выбирает режим «vs год назад»
- **THEN** для каждой из топ-5 категорий отображается пара столбцов: текущий месяц
  и тот же месяц предыдущего года

#### Scenario: Недостаточно исторических данных
- **WHEN** для периода сравнения (прошлый месяц/год назад) нет ни одной транзакции
- **THEN** соответствующий столбец сравнения отображается как нулевой, а не
  скрывает весь график

### Requirement: REST API сравнения периодов

Backend SHALL предоставлять
`GET /api/v1/analytics/period-comparison?mode=prev_month|prev_year`, возвращающий
суммы по топ-5 категориям текущего периода и сопоставимого периода сравнения.

#### Scenario: Запрос сравнения
- **WHEN** клиент запрашивает `GET /api/v1/analytics/period-comparison?mode=prev_month`
- **THEN** ответ `200` содержит до 5 категорий с полями `tag_id`, `name`,
  `current_amount`, `comparison_amount`
