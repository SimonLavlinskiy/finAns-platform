## ADDED Requirements

### Requirement: Арифметическое выражение в поле суммы

Поле «Сумма» в форме добавления транзакции SHALL поддерживать ввод арифметического
выражения (сложение, вычитание, умножение, деление, скобки) вместо одного числа;
при потере фокуса или сохранении транзакции выражение вычисляется, и поле заменяется
на итоговую сумму.

#### Scenario: Сложение нескольких сумм
- **WHEN** пользователь вводит в поле суммы `378+567+844` и убирает фокус с поля
- **THEN** поле показывает вычисленный результат `1789`

#### Scenario: Поддержка всех базовых операций
- **WHEN** пользователь вводит выражение с использованием `+`, `-`, `*`, `/` и/или
  скобок
- **THEN** результат вычисляется согласно стандартному порядку операций

#### Scenario: Обычный числовой ввод не меняется
- **WHEN** пользователь вводит одно число без операторов (как раньше)
- **THEN** поведение поля не отличается от текущего (число сохраняется как есть)

#### Scenario: Некорректное выражение
- **WHEN** пользователь вводит выражение, которое не удаётся вычислить
  (синтаксическая ошибка, деление на ноль)
- **THEN** система показывает стандартную ошибку валидации суммы, поле не
  автозаполняется вычисленным значением
