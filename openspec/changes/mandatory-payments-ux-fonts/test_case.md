## 1. Подсветка регулярного платежа в календаре

<!-- spec: mandatory-payment-calendar-highlight -->

### TC-01: Будущий день с регулярным платежом подсвечивается

| Поле | Значение |
|------|----------|
| Приоритет | High |
| Тип | Positive |
| Спека | Подсветка будущего дня с регулярным платежом → Будущий день совпадает с датой регулярного платежа |
| Шаги | 1. Создать регулярный платёж с `next_payment_date` через несколько дней 2. Открыть календарь расходов на «Операциях» |
| Ожидаемый результат | Столбец этого дня отображается акцентным стилем, отличным от обычных планируемых дней |
| Статус | ☐ |

### TC-02: Подсветка пропадает после наступления дня

| Поле | Значение |
|------|----------|
| Приоритет | High |
| Тип | Negative |
| Спека | Подсветка будущего дня с регулярным платежом → День наступил и прошёл |
| Шаги | 1. Дождаться/симулировать наступление даты регулярного платежа 2. Открыть календарь |
| Ожидаемый результат | День отображается как обычный текущий/прошедший, без спецподсветки, независимо от статуса оплаты |
| Статус | ☐ |

### TC-03: Несколько платежей на одну дату

| Поле | Значение |
|------|----------|
| Приоритет | Medium |
| Тип | Boundary |
| Спека | Подсветка будущего дня с регулярным платежом → Несколько платежей на одну дату |
| Шаги | 1. Создать два регулярных платежа с одинаковой будущей `next_payment_date` |
| Ожидаемый результат | День подсвечен один раз, во всплывающей подсказке перечислены оба платежа |
| Статус | ☐ |

### TC-04: Подсказка при наведении на день без фактических данных

| Поле | Значение |
|------|----------|
| Приоритет | High |
| Тип | Positive |
| Спека | Всплывающая подсказка с регулярным платежом → Наведение на подсвеченный день |
| Шаги | 1. Навести курсор на подсвеченный будущий день (без транзакций за этот день) |
| Ожидаемый результат | Появляется подсказка с наименованием и суммой платежа |
| Статус | ☐ |

### TC-05: Обычный будущий день без платежа не реагирует на наведение

| Поле | Значение |
|------|----------|
| Приоритет | Low |
| Тип | Negative |
| Спека | Всплывающая подсказка с регулярным платежом → Обычный будущий день без платежа |
| Шаги | 1. Навести курсор на будущий день без транзакций и без регулярного платежа |
| Ожидаемый результат | Подсказка не появляется |
| Статус | ☐ |

## 2. Попап подтверждения оплаты

<!-- spec: mandatory-payments -->

### TC-06: Клик «Оплатить» открывает попап, не создаёт транзакцию сразу

| Поле | Значение |
|------|----------|
| Приоритет | High |
| Тип | Positive |
| Спека | Отметка «Оплачено» с созданием транзакции → Открытие попапа подтверждения |
| Шаги | 1. На странице регулярных платежей нажать «Оплатить» |
| Ожидаемый результат | Открывается попап с суммой, транзакция ещё не создана |
| Статус | ☐ |

### TC-07: Подтверждение с изменённой суммой

| Поле | Значение |
|------|----------|
| Приоритет | High |
| Тип | Positive |
| Спека | Отметка «Оплачено» с созданием транзакции → Подтверждение с изменённой суммой |

| Ожидаемый результат | Транзакция создана с новой суммой; сумма самого регулярного платежа не изменилась |
| Статус | ☐ |

### TC-08: Дата транзакции — фактическая, не запланированная

| Поле | Значение |
|------|----------|
| Приоритет | High |
| Тип | Positive |
| Спека | Отметка «Оплачено» с созданием транзакции → Дата транзакции — фактическая, а не запланированная |
| Шаги | 1. Подтвердить оплату платежа, у которого `next_payment_date` отличается от сегодняшней даты |

| Статус | ☐ |

### TC-09: Дата следующего платежа не зависит от даты подтверждения

| Поле | Значение |
|------|----------|
| Приоритет | High |
| Тип | Boundary |
| Спека | Отметка «Оплачено» с созданием транзакции → Дата следующего платежа не зависит от фактической даты оплаты |
| Шаги | 1. Подтвердить оплату с опозданием (после `next_payment_date`) |
| Ожидаемый результат | Новая `next_payment_date` вычислена от исходной запланированной даты по правилу периодичности, а не от даты подтверждения |
| Статус | ☐ |
